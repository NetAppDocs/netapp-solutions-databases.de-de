= Google Cloud NetApp Volumes Workflow zur Bereitstellung einer hochverfügbaren Oracle Database 26ai
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Mit Google Cloud NetApp Volumes iSCSI Blockspeicher lässt sich eine hochverfügbare Oracle Database 26ai mit Oracle Data Guard auf Google Compute Engine bereitstellen. Dieser Workflow bietet einen Überblick über Bereitstellungsoptionen, Infrastruktur-Provisionierung, Oracle Software-Installation und Hochverfügbarkeitskonfiguration, wobei die Storage-Layer-Replikation von GCNV für eine beschleunigte Standby-Initialisierung genutzt wird.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:gcnv-oracle-solution-architecture.html["Die Lösungsarchitektur im Überblick"]
[role="quick-margin-para"]
Die Google Cloud NetApp Volumes Architektur für die Hochverfügbarkeit von Oracle Database 26ai, einschließlich GCNV iSCSI-Blockspeicherdesign, Data Guard-Integration und Speichertopologie.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:gcnv-oracle-deployment-options.html["Bereitstellungsoptionen und Anforderungen überprüfen"]
[role="quick-margin-para"]
Bereitstellungsstufen von Entwicklung/Test bis zur Produktions-HA vergleichen und Infrastruktur-, Zugriffs- sowie Softwarevoraussetzungen bestätigen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:gcnv-oracle-access-and-apis.html["Zugriff und APIs verifizieren"]
[role="quick-margin-para"]
Erforderlicher Zugriff, API-Aktivierung, Netzwerkvoraussetzungen und Zeitsynchronisierung bestätigen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]link:gcnv-oracle-provision-compute.html["Google Compute Engine Instanzen bereitstellen"]
[role="quick-margin-para"]
VMs für die primäre Datenbank, die Standby Datenbank und den Fast-Start Failover Observer erstellen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Fünf"]link:gcnv-oracle-provision-storage.html["GCNV iSCSI Storage bereitstellen"]
[role="quick-margin-para"]
GCNV Storage Pools und iSCSI-Volumes werden erstellt, Multipath wird konfiguriert und ASM Festplattengruppen werden eingerichtet.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sechs"]link:gcnv-oracle-install-software.html["Oracle Grid Infrastructure und Oracle Database 26ai installieren"]
[role="quick-margin-para"]
Die Oracle Grid Infrastructure und die Oracle Database 26ai Software auf beiden Datenbank-Hosts installieren.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["Sieben"]link:gcnv-oracle-primary-database.html["Erstellen Sie die primäre Datenbank"]
[role="quick-margin-para"]
Die primäre Oracle Datenbank mit ASM-Speicher erstellen und Oracle Restart konfigurieren.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-8.png["Acht"]link:gcnv-oracle-standby-database.html["Erstellen Sie die Standby-Datenbank"]
[role="quick-margin-para"]
Die Standby-Datenbank wird mithilfe von GCNV Replikation, Snapshots oder Klonen initialisiert und anschließend bei Oracle Restart registriert. Alle HA-Tiers schließen diesen Schritt ab.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-9.png["Neun"]link:gcnv-oracle-standby-finalize-dg.html["Standby-Datenbank für Data Guard finalisieren"]
[role="quick-margin-para"]
Standby-Redo-Logs erstellen, Flashback aktivieren, Redo-Shipping aktivieren und Data Guard-Status überprüfen. *Tierspezifisch:* Nur für die Prod HA (Data Guard + FSFO) Tier erforderlich.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-10.png["Zehn"]link:gcnv-oracle-data-guard.html["Data Guard Broker und Fast-Start-Failover konfigurieren"]
[role="quick-margin-para"]
Den Broker aktivieren, die Data Guard Konfiguration erstellen, FSFO aktivieren und den Observer konfigurieren. *Tierspezifisch:* Nur für die Prod HA (Data Guard + FSFO) Tier erforderlich.
